# SuiteCRM 19.0 testing

## Source and support boundary

SuiteCRM is not packaged by Debian Trixie. The appliance installs the official
SuiteCRM-Core 8.10.2 production archive from its GitHub release. The build pins
SHA-256
`ac4693d10ea2d6cd20b3256098781d134599d88878fb24e8dc127038d624f5a8`.
SuiteCRM documents PHP 8.4 and MariaDB 11.8 as supported for the 8.10 release
line. The official stable GitHub release feed supplies updater metadata and an
asset digest.

## Acceptance command

Run the repository through the isolated Wave 2 harness:

```sh
TKLDEV_CONTAINER=tkldev19-wave2 \
TKL_HARNESS_STATE_DIR=/home/agent/.local/state/turnkey-v19-harness-wave2 \
TKL_HARNESS_LOCK_FILE=/home/agent/.local/state/turnkey-v19-harness-wave2/build.lock \
/sandboxed-git/turnkey/tools/test-v19-appliance suitecrm \
  --source /home/agent/.local/worktrees/turnkey-apps/suitecrm/wish-suitecrm-v19-trixie
```

## Deferred issues

- The acceptance run performs a non-destructive stable-channel update check.
  Applying a future release remains a supervised administrator operation.
- Confconsole's interactive menu is not automated. Its helper paths and syntax
  are checked, while the main SuiteCRM workflow runs with the default build
  permissions.
